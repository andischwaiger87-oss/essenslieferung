# Essen auf Rädern Fahrplan (Prototyp)

Klickbarer Prototyp für den Sozialsprengel Pillerseetal: Fahrplan der Essenszustellung
für die Routen Fieberbrunn, Hochfilzen und Waidring.

- Eine statische Seite (`index.html`), kein Build-Schritt.
- Schrift Outfit liegt lokal unter `fonts/` (SIL Open Font License), es wird nichts von Dritten nachgeladen.
- Nichts wird gespeichert, alle Änderungen gelten nur bis zum Neuladen.

## Cloudflare Pages

Framework: keines · Build-Befehl: leer · Ausgabeverzeichnis: `/`
